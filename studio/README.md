# Banner Studio — הרצה מקומית עם AI 🗂️

כלי מקומי ליצירת באנרים לאתר: בוחרים נושא לכל באנר, ה‑AI (Google Gemini) יוצר
את תמונת הרקע, ואפשר להוריד את כל הבאנרים בבת אחת. הכל רץ **על המחשב שלך** —
מפתח ה‑API נשמר מקומית ולא נשלח לדפדפן.

---

## מה צריך פעם אחת

### 1. להתקין Node.js
אם עדיין אין לך — להוריד מ‑<https://nodejs.org> (הגרסה עם "LTS") ולהתקין.
כדי לבדוק שהתקנת: לפתוח טרמינל ולהריץ `node -v` — צריך להופיע מספר גרסה (18 ומעלה).

### 2. להשיג מפתח Gemini
עם חשבון ה‑Gemini Pro שלך, להיכנס ל‑<https://aistudio.google.com/apikey>,
ללחוץ **Create API key**, ולהעתיק את המפתח.

### 3. להכניס את המפתח
בתיקייה `studio`:
1. להעתיק את הקובץ `.env.example` ולקרוא לעותק `.env`
2. לפתוח את `.env` ולהחליף את `your_key_here` במפתח שהעתקת. לשמור.

> הקובץ `.env` נשאר רק אצלך במחשב (הוא ב‑`.gitignore`), המפתח אף פעם לא נשלח לאף אחד.

---

## איך מריצים (בכל פעם)

לפתוח טרמינל בתיקייה `studio` ולהריץ:

```bash
npm install     # רק בפעם הראשונה — מתקין את החבילות
npm start
```

ואז לפתוח בדפדפן: **<http://localhost:8787>**

בטרמינל תראי הודעה `✓ AI is active` — סימן שהמפתח נקלט.
לעצור את השרת: `Ctrl + C` בטרמינל.

---

## איך עובדים בכלי

1. לכל באנר יש ריבוע עם המידה שלו. לוחצים על ריבוע כדי להיכנס לעריכה.
2. כותבים **נושא לתמונה** (למשל *a happy family in front of a suburban home*) ולוחצים
   **✨ Generate with AI** — הרקע נוצר. אפשר גם להעלות תמונה משלך במקום.
3. שולטים בטקסטים, לוגו, overlay, מיקום התמונה וכו' לכל באנר בנפרד.
4. מסמנים את הבאנרים שרוצים, בוחרים פורמט (PNG/JPG/WebP) ומשקל מקסימלי משותף,
   ולוחצים **Run selected** — כל הבאנרים נוצרים ונשמרים אוטומטית לתיקייה `studio/output`.

---

## שאלות נפוצות

**לא רואה `✓ AI is active`.** ודאי ששם הקובץ הוא בדיוק `.env` (לא `.env.txt`) ושהמפתח
הודבק במלואו, ואז הריצי `npm start` מחדש.

**רוצה לשמור במקום אחר.** אפשר להוסיף ל‑`.env` שורה כמו `OUTPUT_DIR=/path/to/folder`.

**בלי מפתח בכלל.** הכלי עדיין עובד — פשוט מעלים תמונות ידנית במקום ליצור עם AI.
